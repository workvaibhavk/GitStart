## 🌟 What is GitStart?

Many beginners want to contribute to open source but don't know where to start. Git feels confusing, GitHub workflows are unclear, and the fear of making mistakes keeps people away.

**GitStart** fixes that. It's a simple, clean web platform that teaches Git concepts visually, walks you through the full GitHub contribution workflow, and lets you practice real commands in an interactive terminal — all in one place.

**No prior experience needed. Just open it and start learning.**

## ✨ Features

- **Git Concepts** — Clear explanations of repository, commit, branch, merge, push/pull, and fork with real command examples
- **GitHub Workflow Guide** — Step-by-step walkthrough of the full fork → clone → branch → commit → PR workflow
- **Interactive Practice Terminal** — Type real Git commands and get instant simulated responses; 12 guided missions from Beginner to Advanced
- **Live Git State Visualizer** — Watch your repo state, branches, staged files, and commit log update in real time as you practice
- **Contribution Guide** — Learn what to contribute, how to write good commit messages, and where to find beginner-friendly projects
- **Curated Resources** — Hand-picked links to the best Git learning tools

## 🚀 How to Use

### Option 1 — Open Directly (No Install Needed)

1. Download or clone this repo
2. Open `index.html` in your browser
3. Start learning!

### Option 2 — Clone and Run Locally

```bash
git clone https://github.com/workvaibhavk/gitstart.git
cd gitstart
open index.html
```

### Option 3 — GitHub Pages (Live)

Visit the live demo: [gitstart](https://gitstartt.netlify.app)

## 🤝 Contributing

We love contributions! GitStart is a beginner-friendly project — your first PR is welcome here.

Read our **[Contributing Guide](CONTRIBUTING.md)** to get started.

**Quick steps:**

```bash
# 1. Fork this repo on GitHub
# 2. Clone your fork
git clone https://github.com/workvaibhavk/gitstart.git

# 3. Create a branch
git checkout -b feature/your-feature-name

# 4. Make your changes, then commit
git commit -m "feat: describe what you changed"

# 5. Push and open a Pull Request
git push origin feature/your-feature-name
```
